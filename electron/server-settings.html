Chọn nguồn dữ liệu cho server

URL được lưu riêng cho IsleOverlay. Bạn có thể chuyển server mà không cần sửa file cấu hình thủ công.

Đây là đường dẫn trang IslePilot để ghi nhớ server. Với IslePilot hiện tại, trang này thường không phải URL API.

Có thể nhập cả path, ví dụ https://islepilot.eu/p/sbtcisland, nếu backend của bạn thực sự đặt API dưới prefix đó.

API hiệu dụng-

Sau khi đổi server, hãy đăng nhập Steam lại nếu token hiện tại thuộc server cũ. Nút kiểm tra chỉ gọi endpoint không làm thay đổi dữ liệu: /api/overlay/me.

IsleOverlay giữ URL trang server và API base độc lập để hỗ trợ cả IslePilot chuẩn lẫn backend có path prefix.
